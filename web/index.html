Aide & contrôles

Objectif : creusez la montagne, automatisez la forge, défendez le cœur ♜ contre les vagues de monstres.

PC : clic = outil · clic droit/milieu + glisser = caméra · molette = zoom · 1-9 = outils · R = tourner · Espace = pause · Échap = annuler.

Mobile : 1 doigt = outil (glisser = tracer) · 2 doigts = caméra + pinch-zoom · bouton « ✋ Caméra » = déplacer à 1 doigt.

Chaîne : foreuse sur un filon creusé → tapis → fonderie (fer + charbon) → tapis → cœur. Les lingots servent de munitions aux tourelles.
